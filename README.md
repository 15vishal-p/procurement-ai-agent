# Procurement AI Agent

A FastAPI service exposing Slovak public procurement data (from Snowflake) as a REST API - the foundation for an MCP server and LangChain agent built on top of it.

This project is built on top of the data pipeline in [eks-procurement-etl-pipeline](https://github.com/15vishal-p/eks-procurement-etl-pipeline), which loads the underlying data into Snowflake. This repo doesn't touch the data pipeline itself - it's about exposing that data through an API and, eventually, to AI agents.

## Phase 1: FastAPI Backend (current)

Read-only REST API with three endpoint groups:

- `GET /contracts` - list/search contracts, paginated
- `GET /contracts/{id}` - get a single contract
- `GET /buyers/top` - top buyers by total spend
- `GET /stats/summary` - overall dataset statistics

## Setup

1. Create and activate a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Mac/Linux
   ```
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Copy `.env.example` to `.env` and fill in your Snowflake credentials.

## Run it

```
uvicorn app.main:app --reload
```

Then open http://127.0.0.1:8000/docs for interactive API documentation (auto-generated by FastAPI).

## Structure

```
app/
  main.py          - FastAPI app, wires up routers
  config.py        - loads Snowflake credentials from .env
  db.py            - SQLAlchemy connection + query helper
  models.py        - Pydantic response models
  routers/
    contracts.py   - contract listing/lookup endpoints
    buyers.py       - buyer spend analysis endpoints
    stats.py        - dataset summary endpoint
```
